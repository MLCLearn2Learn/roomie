# Roomie Coach friend trial

Public route: https://mlclearn2learn.github.io/roomie/coach/
Entry: Roomie app → Setup → Coach (early access) → Open Roomie Coach. Separate tab; no automatic microphone or class-data transfer. Existing lesson mirror reports remain under a separate disclosure.

This is an early-access prototype: authored coaching pathways, teacher-reviewed evidence, strategy-specific AERO links, rehearsal, next-step plans, peer summaries and a deliberate Claude copy/paste handoff. No connected AI inference or automated slide-content analysis.

Optional local-only speech recognition requires browser support and a local English pack. No cloud speech fallback. Manual notes work without microphone permission. Pause/stop release media; delayed permission grants are cancelled safely. Files/screens stay local and are not persisted. No audio is recorded or saved.

Reviewed reflections save deliberately in origin-local browser storage, separate from classroom profile data. No cloud backup or cross-device sync. Original recognised speech is not saved in reflection records or automatically copied to Claude/peers. Optional extracts/material text/private reflection are excluded from peer summaries by default. Teachers review exact copy text and choose where to paste.

Friends can open the public route without the owner-only ChatGPT preview sign-in. Do not share browser backups or private lesson extracts when sharing the public link. Classroom consent and browser compatibility still need real-device checks. This release does not validate AI effectiveness.
