# Roomie improvement roadmap

These are proposed development priorities, not claims of completed features.
Production remains gated on Antoinette's explicit approval.

## 1. Easier teaching flow
Walk through first class setup, timetable, starting a lesson, changing activity and finishing.
Identify repeated clicks, confusing labels and interruptions.
Make the smallest coherent navigation improvement supported by that walkthrough.
Preserve teacher custom dock order and hidden tools.

## 2. Confidence in saved work
Make existing save/backup state easier to understand and recover from.
Check storage-full, failed imports, missing media and accidental replacement flows.
Preserve local data and distinguish settings backups from media coverage.

## 3. Visual polish and accessibility
Review information hierarchy, spacing, projector legibility and narrow-screen setup.
Verify keyboard focus, modal behavior, readable contrast and reduced-motion preferences.
Avoid decorative changes that make classroom controls harder to find.

## 4. Release confidence
Finish hosted transfer staging verification, operational abuse controls and cleanup review.
Test realistic fictional transfers between two browser/device contexts.
Prepare a concrete release review for Antoinette before any production changes.

## Completion standard
For each pass record: user problem, resulting behavior, files/commit, checks performed, and remaining limits.
Keep HANDOVER.md current so either Claude or ChatGPT can continue.
